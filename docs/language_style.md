# ANJANEY Language Style Guide: Non-Diagnostic Communication

1. **Screening, Never Diagnosing:**
   - BANNED: "You have depression", "Depression detected", "Clinical diagnosis", "PHQ-8 diagnostic score".
   - PERMITTED: "Your check-in pattern differs from your usual baseline", "Elevated distress risk signal", "Usual-range trend".

2. **Contributions, Never Causations:**
   - Explain features as associative factors ("Changes in response pacing contributed to this reading") rather than biological causes.

3. **Always Offer Next Steps:**
   - Every alert provides calm options: talking to a peer supporter, booking a confidential counselor check-in, or reviewing sleep/work habits.
